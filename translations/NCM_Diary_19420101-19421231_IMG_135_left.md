mañana. En el Tamand decidimos renunciar 
la concesión Hernando Valencia, y de acuerdo

para una nueva concesión. Las tres aplicaciones sobre el

presente. Probablemente serán renunciados más adelante. 
pero esto es para darle más tiempo para decidir, y 
también para no tener todas las renuncias
